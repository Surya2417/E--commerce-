# E-Commerce Data Analysis & Insights

## Overview
This project performs Exploratory Data Analysis (EDA) on an e-commerce sales dataset (`Sample - Superstore.csv`) to uncover insights related to sales performance, profit margins, product categories, and customer segmentation.

## Repository Structure
- `Sample - Superstore.csv`: The main transactional dataset.
- `sample data analyse.ipynb`: Jupyter Notebook containing data cleaning, visual analysis, and statistical computations.
- `Untitled.ipynb`: Additional analysis workspace notebook.
- `anaconda_projects/`: Environment configurations.
- `project_filebrowser.db`: Local database file for data tracking.

## Tools & Libraries Used
- **Python**: Core programming language.
- **Pandas / NumPy**: Data manipulation and preprocessing.
- **Matplotlib / Seaborn**: Data visualization.
- **Jupyter Notebook**: Interactive development environment.
